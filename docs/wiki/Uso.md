# Uso

Pulsa **Nueva petición**, introduce la URL de TMDB y completa peticionario, estado, método y enlace de descarga.

La lista permite filtrar por título, estado, tipo y peticionario. Haz doble clic sobre una fila para editarla.

Estados: 📨 Solicitado, 🔎 Buscando, 📥 Descargado, 📤 Subido y ✅ Notificado.

Los peticionarios se gestionan desde **Ajustes → Gestionar peticionarios…**.
